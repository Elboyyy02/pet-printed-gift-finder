# Pet Printed Gift Finder

A guided gift discovery experience designed to help customers find personalized, thoughtful gifts based on their recipient, interests, preferences, and occasion.

**Live app**: https://pet-printed-gift-finder.lovable.app

##  Project Overview

The Pet Printed Gift Finder is a prototype designed to simplify gift shopping through a guided questionnaire and personalized product recommendations.

Instead of browsing through a large catalog, users answer a series of simple, connected questions. Based on their responses, the experience helps them discover relevant products from the catalog, with a reason explaining why each recommendation may be a good fit.

The goal is to make gift discovery easier, more engaging, and more personalized while helping customers move from inspiration to product selection.

## How It Works

1. Answer the questions — Share who the gift is for, the occasion, and relevant preferences.

2. Refine the preferences — Select the product type and other details that help narrow the options.

3. Explore recommendations — Review suggested products that align with the answers provided.

4. Discover the right gift — Check product details, pricing, and links to explore or purchase the item.

## Project Goals

- Simplify the gift discovery process.

- Help customers find products that better match their needs.

- Make product recommendations easier to understand.

- Create a user-friendly shopping experience that encourages product exploration.

- Demonstrate how a guided product finder can support an e-commerce customer journey.

## Project Status

**Status**: Prototype

This project demonstrates a guided gift discovery experience and can be further developed with improvements to product matching, recommendation logic, analytics, and e-commerce integrations.

## Development

Prefer working locally? You need Node.js and npm — install with nvm. 

- [Node.js](https://nodejs.org/)

- npm (included with Node.js)

## Installation

1. Clone the repository: 

  git clone https://github.com/Elboyyy02/pet-printed-gift-finder.git

2. Navigate to the project directory:

  cd pet-printed-gift-finder

3. Install dependencies:

  npm install

4. Start the development server:

  npm run dev

5. Open the local URL displayed in your terminal.
